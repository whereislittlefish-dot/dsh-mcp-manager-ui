# MCP 服务器面板

从左侧栏打开的 MCP 服务器页面。它不自己连接 MCP 服务器，而是驱动 Harness 里已经挂载的 `@deepseek-ai/dsh-mcp-manager`：读它的连接状态，写它的 profile 配置，所以页面上的每一次改动和「设置」里的编辑走的是同一条路径。

## 能做什么

- **查看**：每个服务器的连接状态（已连接 / 连接中 / 重连中 / 等待凭据 / 已停用 / 失败）、工具数量、传输方式、命令或地址、环境变量与请求头的**键名**；展开「详情」看参数、工作目录、超时、最近错误与该状态的处置建议。
- **新建**：本地命令（stdio）或 HTTP 端点（streamable-http）。参数每行一个；环境变量与请求头每行 `KEY=VALUE`。
- **修改**：名称、传输方式、命令、参数、工作目录、环境变量、地址、请求头、单次工具调用超时；改名会提示模型侧工具名变化。
- **启用 / 停用**：停用会保留配置但断开连接，该服务器的工具同时从模型的工具集中移除。
- **重启**：重建实例并重置重连预算（连续重连失败、预算耗尽后用它恢复）。
- **测试连接**：在不影响线上实例的前提下解析模板、连接、列出工具名、关闭；停用的服务器也能测。
- **删除**：走确认弹层，写清后果后才可点确认。

## 边界

- **来自下层配置的服务器不能在这里删除**：bundle 或 profile 基线提供的条目删掉后会被下层恢复，因此确认层只提供「停用」，并在按钮上直接写「停用」。
- **插件注册的服务器只读**：这类条目由插件在自身生命周期内注册，页面只显示状态；插件卸载时它们自然消失。
- **删除后清理未完成的条目**显示为「残留记录」并禁止复用同名：连接关闭无法确认时，重启 Harness 才会清掉记录。
- **配置写入活动 profile 的 `cordis.patch.yml`**，与「设置」写的是同一份文件；命令行覆盖或 home patch 的更高优先级会让写入被拒绝并报错。
- **密钥请用凭据模板**：`env` / `headers` / `command` / `args` / `cwd` / `url` 支持 `${credential:名称}`，值保存在凭据提供方而不是配置里。列表只显示键名，编辑表单默认隐藏值，需要编辑时点「显示值」。
- 工具名固定为 `mcp__<名称>__<工具>`，名称只允许字母、数字、下划线和短横线（1–32 位）。

## 状态与处置

| 状态 | 含义与下一步 |
|---|---|
| 已连接 | 工具已提供给模型 |
| 连接中 / 重连中 | 自动进行；持续失败时点「重启」 |
| 等待凭据 | 配置里的 `${credential:名称}` 没有解析到值，补凭据或改成直接填写 |
| 已停用 | 配置保留、不连接 |
| 失败 | 详情给出 `reason` 对应建议：重连预算耗尽 → 重启；自动重连关闭 → 重启或开启重连；加载失败 → 重启并检查命令/地址；清理未确认 → 重启 Harness |

## 使用

1. 在左侧栏点「MCP 服务器」图标（展开态显示文字，折叠态显示图标与悬浮提示）。
2. 「新建服务器」选择接入方式并填写参数，保存后立刻写入配置并开始连接。
3. 行内开关控制启停；「详情」展开配置与测试/重启/删除操作。
